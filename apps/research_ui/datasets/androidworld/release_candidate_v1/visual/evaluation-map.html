PoC scope. Six hundred logical reference pairs derive target values from three pinned AndroidWorld task generators. All 600 controls satisfy their offline predicate and all 600 faults violate it. UI rectangles, transition keys, lifecycle effects, and feedback timestamps are authored reference examples. Live fixture/capture adapters must enact these cases before agent benchmarking. Five existing emulator fixture observations remain separately recorded. No agent outcomes or human tier-calibration labels are claimed.
